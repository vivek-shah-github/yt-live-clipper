YT LIVE CLIPPER 2.0  (Windows / Mac)
====================================

START
  Windows : double-click run.bat
  Mac     : double-click run.command  (first time: right-click > Open)
  Needs Python 3.9+ (python.org). Everything else installs automatically.
  The app opens in its own window (Edge / Chrome). Keep the small black
  (Terminal) window open while you use it. Closing the app window stops it.

CLIP AN ENDED LIVE STREAM (or any video)
  1. Paste the YouTube link > Load. The video plays in the preview.
  2. Mark a part, any of these ways:
       - Drag across the timeline strip under the video
       - Play the video and press "Set to now" (or the I and O keys)
       - Type the times (1:02:30, 62:30, 1h2m30s or 3750 all work)
     Fine-tune with the yellow edges, the -1 / +1 buttons, or zoom (+ / - / Fit).
     Press Preview to watch just that part.
  3. Add clip. Repeat for as many clips as you want (click a clip to edit it).
  4. Export. MP4 files land in the "Save to" folder (Settings).
     The clip list is remembered for each video, even after closing the app.

RECORD A STREAM THAT IS LIVE NOW
  1. Paste the live link > Load (it shows LIVE)
  2. Press the red button the moment you want to start
  3. Press it again to stop and save. If the stream ends, it saves on its own.
  Tip: for a moment that already happened in a live stream, wait until the stream
  ends, then Load it again and clip it.

KEYBOARD
  I = start here   O = end here   Enter = add clip   P = preview
  Space = play/pause   Left/Right = seek 5 s (Shift: 1 s)

SETTINGS (gear icon, top right)
  Quality       : max resolution (falls back to the next best available)
  Vertical 9:16 : centre-cropped 1080x1920 for Shorts / Reels (the dashed box
                  on the preview shows what will be kept)
  Sign-in from browser : for members-only / age-restricted streams
  Update yt-dlp : click this if loading suddenly fails (YouTube changes often),
                  then restart the app

Use it on your own streams or content you have permission to reuse.
